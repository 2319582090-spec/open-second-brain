# Contributing

Open Second Brain is a community project for people building AI-native personal memory systems. Contributions can be code, research, hardware notes, design proposals, privacy models, schemas, or practical experiments.

## Who Should Contribute

We welcome:

- AI engineers working on memory, retrieval, multimodal understanding, agents, and model routing.
- Hardware builders working on wearables, smart glasses, audio recorders, sensors, and home devices.
- App developers connecting desktop, mobile, browser, and cloud workflows.
- Privacy and security researchers designing local-first personal data systems.
- Designers exploring how people should review, search, correct, and talk to life memory.
- Users testing real workflows and reporting what is useful or uncomfortable.

## How to Start

1. Read the README and architecture.
2. Open an issue using the idea, hardware, or integration template.
3. Describe what you are building or what you want to test.
4. Link to prototypes, repos, docs, videos, diagrams, or notes.
5. Keep privacy and consent in the proposal from the beginning.

## Good Contributions

Useful contributions include:

- A working adapter for a capture tool.
- A proposed schema for personal memory episodes.
- A comparison of wearable devices.
- An MCP server prototype.
- A local-first storage design.
- A redaction or consent model.
- A UX sketch for daily review or memory search.
- A benchmark for recall quality.

## Contribution Principles

- Do not normalize surveillance.
- Do not assume every person wants every moment recorded.
- Do not upload raw sensitive personal data to cloud services by default.
- Do not build around a single closed vendor.
- Prefer open APIs, export formats, and user-owned data.
- Make privacy controls visible and understandable.
