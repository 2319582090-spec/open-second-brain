# Roadmap

This roadmap starts with a community map and moves toward a working 24-hour AI-native second brain.

## Phase 0: Community Launch

- Publish the project manifesto and architecture.
- Collect existing tools, hardware, protocols, and research.
- Open issue templates for ideas, hardware, and integrations.
- Invite builders from AI memory, lifelogging, wearables, local-first software, and MCP ecosystems.

## Phase 1: Minimum Viable Second Brain

Goal: create a working reference pipeline that captures, summarizes, and recalls a user's day from a small set of sources.

Initial sources:

- Desktop screen/OCR/audio from Screenpipe.
- Conversation memories from Omi or a similar recorder.
- Work context from Pieces OS.
- Manual voice or text notes.

Initial outputs:

- Daily timeline.
- Searchable episode database.
- Personal memory API.
- MCP endpoint for AI tools.
- Local-first storage and retention settings.

## Phase 2: Unified Memory Schema

Goal: define an interoperable schema for personal memory events.

Work items:

- Episode schema.
- Source adapters.
- Privacy levels.
- Retention rules.
- Entity and relationship format.
- Export package format.

## Phase 3: AI Understanding Pipeline

Goal: make raw life data understandable and searchable.

Work items:

- OCR pipeline.
- Speech-to-text pipeline.
- Image and video understanding.
- Entity extraction.
- Timeline summarization.
- Action-item extraction.
- Contradiction and update handling.

## Phase 4: Temporal Knowledge Graph

Goal: move from chunks to evolving personal knowledge.

Work items:

- Temporal graph ingestion.
- Entity resolution.
- Fact validity windows.
- Relationship history.
- Query examples.
- Graph visualization.

## Phase 5: Hardware Ecosystem

Goal: make hardware integrations practical.

Device classes:

- Audio pendants.
- Smart glasses.
- Phones.
- Watches.
- Cameras.
- Health and environment sensors.

Requirements:

- Open APIs where possible.
- Visible recording state.
- Consent-aware capture.
- Local buffering.
- Export and deletion.

## Phase 6: Personal AI Interfaces

Goal: let people talk to their memory through the tools they already use.

Targets:

- MCP clients.
- Desktop assistant.
- Mobile assistant.
- Browser extension.
- Codex and developer tools.
- Chat and voice assistants.
- Doubao and other model providers through API gateways.

## Phase 7: Safety, Privacy, and Governance

Goal: make a 24-hour memory system socially and legally usable.

Work items:

- Redaction policies.
- Sensitive-scene detection.
- Bystander consent patterns.
- Local-first defaults.
- Encrypted sync.
- Audit logs.
- Data minimization.
- User-owned export.
